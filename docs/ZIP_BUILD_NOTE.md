# ZIP build note

This ZIP was assembled from the current public repository structure and the new Slack Canvas cleaning implementation.

The connected GitHub interface available during packaging could read the repository text files but could not export the original binary `scripts/Presentation_template.pptx` directly. The ZIP therefore carries forward the compatible replacement template from the previous generated package.

If the live repository contains a customized/branded PowerPoint template, copy the original `scripts/Presentation_template.pptx` from the live repository over the file in this ZIP before replacing or uploading the repository contents. The Slack Canvas cleaning workflow does not use the PowerPoint template.
